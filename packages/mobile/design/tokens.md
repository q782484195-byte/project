## 字号（px，375 稿）

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| Display | 22 | 600 | 页面大标题、登录品牌 |
| Title | 17 | 600 | 区块标题、任务标题 |
| Body | 15 | 400 | 正文、输入、按钮 |
| Caption | 13 | 400 | 辅助信息、meta |
| Mini | 12 | 400 | 时间、标签、调试文案 |

## 间距 / 圆角 / 高度

间距以 8 的倍数；页面左右 **16px**。圆角：标签 6、输入/按钮 10–12、Chip/头像 full。

| 元素 | 高度 |
|------|------|
| 导航栏 | 44 |
| TabBar | 50 + safe |
| 输入 / 主按钮 | 48 |
| ActionBar | 56 + safe |
| Chip | 32 |
| 快捷入口图标区 | 44 |

## 组件规则

- **TaskRow**：左 3px 色条 + 标题 + meta；可选右侧文字操作；无厚卡片阴影。
- **QuickGrid**：2×2 或 1×4 快捷入口，图标浅底 + 文案。
- **AlertBanner**：逾期/重要提示，浅橙底，可点进列表。
- **Segment**：状态分段控件（全部/待办/进行中/完成）。
- **Timeline**：详情页动态，左轴 + 时间 + 文案。
- **FAB**：右下角圆形主色按钮（仅任务列表）。
- **StatStrip / FilterBar / ActionBar / StatusTag / TabBar**：同前，主色改为蓝。
