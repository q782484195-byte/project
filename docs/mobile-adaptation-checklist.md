## 二、部分适配（仅横向滚动/分页/小屏样式，建议增强）

### 1. 层级管理 `src/views/requirements/index.vue`

- **现状**：有 `isMobile`、分页简化、640px 下表格横向滚动 + 单元格 padding/字号缩小。
- **缺失**：  
  - 顶部筛选区（选择项目、选择层级、状态筛选、新建按钮）未做移动端纵向/折叠。  
  - 表格未改为卡片，列多时横向滚动体验一般。
- **建议**：  
  - 移动端：筛选区纵向排列或折叠为「筛选」按钮弹出。  
  - 可选：≤768px 表格改为卡片列表（层级名称、项目、状态、优先级、操作）。

### 2. 我的任务 `src/views/tasks/my-tasks.vue`

- **现状**：640px 下表格横向滚动、单元格缩小。
- **缺失**：  
  - 搜索表单始终 `inline`，移动端易挤在一起。  
  - 无卡片视图，仅表格横向滚动。
- **建议**：  
  - 移动端表单纵向排列，输入框/下拉全宽。  
  - 可选：≤768px 任务列表改为卡片（任务名、层级、状态、优先级、进度、操作）。

### 3. 任务详情 `src/views/tasks/detail.vue`

- **现状**：`isMobile` 控制描述列数；640px 下汇报列表、BUG 列表表格横向滚动。
- **缺失**：  
  - 汇报列表、BUG 列表在移动端仍为表格，列多时需左右滑动。
- **建议**：  
  - ≤768px 汇报列表、BUG 列表改为卡片列表（每条记录一张卡片）。

### 4. 部门任务统计 `src/views/tasks/department-task-statistics.vue`

- **现状**：640px 下表格横向滚动、单元格缩小。
- **缺失**：  
  - 多层级 Tab + 每 Tab 内表格，移动端仅靠横向滚动。
- **建议**：  
  - Tab 栏保持横向滑动；  
  - 当前 Tab 内任务列表在 ≤768px 改为卡片列表。

### 5. 项目详情 `src/views/projects/detail.vue`

- **现状**：`isMobile` 隐藏部分 Tab（项目统计、项目节点）；640px 下 BUG 列表等表格横向滚动。
- **缺失**：  
  - BUG 列表等表格在移动端仍为表格。
- **建议**：  
  - BUG 列表在 ≤768px 改为卡片列表。

### 6. 需求/层级详情 `src/views/requirements/detail.vue`

- **现状**：640px 媒体查询、表格横向滚动。
- **缺失**：  
  - 若有列表类表格，未做卡片化。
- **建议**：  
  - 根据实际列表结构，在 ≤768px 增加卡片视图或至少保证横向滚动 + 触控友好。

## 四、系统管理（用户/部门）

### 1. 用户管理 `src/views/system/user/index.vue`

- **现状**：640px 下表格横向滚动、表单项样式调整；使用 `pure-table`。
- **缺失**：  
  - 查询表单始终 `inline`，移动端建议纵向或折叠。  
  - 表格未做卡片视图。
- **建议**：  
  - 移动端表单纵向 + 全宽；  
  - 可选：小屏下 `pure-table` 区域用卡片列表展示用户列表。

### 2. 部门管理 `src/views/system/department/index.vue`

- **现状**：640px 下表格横向滚动；使用 `pure-table`（树形）。
- **缺失**：  
  - 树形表格在窄屏上横向滚动 + 层级缩进体验一般。
- **建议**：  
  - 移动端可考虑「扁平列表 + 缩进/面包屑」或折叠展开的卡片列表，便于触控。

## 七、建议优先级（可分批做）

1. **高**：  
   - **我的任务**：表单纵向 + 可选卡片列表（使用频率高）。  
   - **层级管理**：顶部筛选移动端收纳/纵向 + 可选卡片列表。
2. **中**：  
   - **任务详情**：汇报/BUG 列表卡片化。  
   - **部门任务统计**：当前 Tab 任务列表卡片化。  
   - **项目详情**：BUG 列表卡片化。
3. **低**：  
   - **用户管理 / 部门管理**：表单纵向 + 表格或列表展示优化。  
   - **需求详情**：按实际列表结构补充卡片或滚动优化。

## 八、统一约定（便于后续维护）

- **断点**：  
  - `768px`：表格→卡片、复杂表单纵向、主要移动端布局切换。  
  - `640px`：进一步缩小 padding/字号、分页简化等。
- **移动端列表**：  
  - 优先「卡片列表」替代多列表格；  
  - 卡片内：标题 + 标签 + 若干行（label-value）+ 操作按钮。
- **表单**：  
  - 移动端使用 `:inline="false"` 或 `label-position="top"`，表单项/输入框全宽。
- **弹窗**：  
  - 移动端宽度建议 `calc(100% - 24px)` 或约 95%，避免贴边。
